# Practice Intelligence Execution Roles

These are execution roles, not necessarily autonomous agents.

The roles below are implemented by deterministic tools, services and
Orchestrator functions wherever possible.

Kira owns:

- interpretation
- organisational reasoning
- qualification judgement
- opportunity hypotheses
- decision-maker prioritisation
- outreach strategy

Orchestrator owns:

- execution
- task creation
- approval gates
- connector calls
- delivery
- outcome recording

The system should not create an autonomous agent where a deterministic function or tool is sufficient.

## Research

Responsibilities:

- search public sources
- retrieve websites
- identify relevant pages
- capture evidence

## Technology Detection

Responsibilities:

- identify booking providers
- identify PMS references
- identify AI receptionist technology
- identify relevant digital infrastructure

## Practice Analysis

Responsibilities:

- structure practice information
- extract operational signals
- identify likely administrative workload

The reasoning model remains owned by Kira.

## Decision Maker Identification

Responsibilities:

- identify owners
- identify managers
- identify operational leaders
- rank candidates
- provide evidence

## Outreach

Responsibilities:

- transform Kira's outreach principles and opportunity hypothesis into a
  personalised draft
- prepare approval request
- send only after approval

## Learning

Responsibilities:

- capture outcomes
- normalise responses
- store structured feedback
- return learning to the Kira memory/governance system

## Future agent candidates

Do not implement these as autonomous agents until justified:

- autonomous research agent
- autonomous qualification agent
- autonomous outreach agent
- autonomous learning agent

The initial system should prefer deterministic tools plus Kira reasoning.
